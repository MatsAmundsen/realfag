# Matteguiden 1T

Statisk SPA for matematikk 1T med oppgaver, ressurser (brøk, kvadratrot, programmering), progresjonssporing og innebygd Python-kodeskriver.

## Kjør lokalt
Åpne `Indeks.html` i nettleser, eller bruk en enkel server:
```
npx serve .
```

## Bygg
```
node build.js
node scripts/prepare-dist.js
```
