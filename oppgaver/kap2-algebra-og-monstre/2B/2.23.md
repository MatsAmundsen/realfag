Forenkle:

**a)** $(2x - 1)^2$

**b)** $(2x - 1)^2 - (2x + 1)(2x - 1)$

**c)** $(x + y)^2 - (x - y)^2$

## Hint

Regn ut hver kvadratsetning for seg, og trekk deretter sammen like ledd.

## Fasit

**a)**
$(2x - 1)^2 = 4x^2 - 4x + 1$

**Svar:** $4x^2 - 4x + 1$

[STEG]

**b)**
$(2x - 1)^2 - (2x + 1)(2x - 1) = (4x^2 - 4x + 1) - (4x^2 - 1) = 4x^2 - 4x + 1 - 4x^2 + 1 = -4x + 2$

**Svar:** $-4x + 2$

[STEG]

**c)**
$(x + y)^2 - (x - y)^2 = (x^2 + 2xy + y^2) - (x^2 - 2xy + y^2) = x^2 + 2xy + y^2 - x^2 + 2xy - y^2 = 4xy$

**Svar:** $4xy$
