Skriv så enkelt som mulig:

**a)** $\dfrac{2}{3} + 1 - \dfrac{5}{9}$

**b)** $\dfrac{1}{2x} - \dfrac{3 - x}{3x}$

**c)** $\dfrac{x}{4x + 8} + \dfrac{1}{12} - \dfrac{4x + 5}{6x + 12}$

## Hint

Fellesnevner i **a)** er $9$. I **b)** er fellesnevner $6x$. I **c)** faktoriser nevnerne først: $4x+8 = 4(x+2)$ og $6x+12 = 6(x+2)$.

## Fasit

**a)**
$1 = \dfrac{9}{9}$, $\dfrac{2}{3} = \dfrac{6}{9}$

$\dfrac{6}{9} + \dfrac{9}{9} - \dfrac{5}{9} = \dfrac{10}{9}$

**Svar:** $\dfrac{10}{9}$

[STEG]

**b)**
Fellesnevner $6x$:
$\dfrac{1}{2x} = \dfrac{3}{6x}$, $\dfrac{3-x}{3x} = \dfrac{2(3-x)}{6x} = \dfrac{6-2x}{6x}$

$\dfrac{3}{6x} - \dfrac{6-2x}{6x} = \dfrac{3 - 6 + 2x}{6x} = \dfrac{2x - 3}{6x}$

**Svar:** $\dfrac{2x - 3}{6x}$

[STEG]

**c)**
$4x + 8 = 4(x + 2)$ og $6x + 12 = 6(x + 2)$.

$\dfrac{x}{4(x+2)} + \dfrac{1}{12} - \dfrac{4x+5}{6(x+2)}$

Fellesnevner $12(x+2)$:
$\dfrac{3x}{12(x+2)} + \dfrac{x+2}{12(x+2)} - \dfrac{2(4x+5)}{12(x+2)} = \dfrac{3x + x + 2 - 8x - 10}{12(x+2)} = \dfrac{-4x - 8}{12(x+2)}$

$\dfrac{-4(x+2)}{12(x+2)} = -\dfrac{4}{12} = -\dfrac{1}{3}$ (for $x \neq -2$)

**Svar:** $-\dfrac{1}{3}$
