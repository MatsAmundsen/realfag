Regn ut og trekk sammen:

**a)** $(a + 1)^2 - a(2 - a)$

**b)** $(x + 4)^2$

**c)** $(2b + 5)(2b - 5)$

## Hint

$(a+b)^2 = a^2 + 2ab + b^2$ og $(a+b)(a-b) = a^2 - b^2$. I **a)** må du også gange inn minustegnet foran $a(2-a)$.

## Fasit

**a)**
$(a + 1)^2 = a^2 + 2a + 1$

$a(2 - a) = 2a - a^2$

$(a + 1)^2 - a(2 - a) = a^2 + 2a + 1 - (2a - a^2) = a^2 + 2a + 1 - 2a + a^2 = 2a^2 + 1$

**Svar:** $2a^2 + 1$

[STEG]

**b)**
$(x + 4)^2 = x^2 + 2 \cdot x \cdot 4 + 4^2 = x^2 + 8x + 16$

**Svar:** $x^2 + 8x + 16$

[STEG]

**c)**
$(2b + 5)(2b - 5) = (2b)^2 - 5^2 = 4b^2 - 25$

**Svar:** $4b^2 - 25$
