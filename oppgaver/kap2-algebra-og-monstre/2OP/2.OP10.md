**a)** Hva gjør dette programmet? Oppgi alle tallene som skrives ut.

```python
n = 1
while n < 11:
    print(n)
    n = n + 1
```

**b)** Hva gjør dette programmet? Hva blir skrevet ut til slutt?

```python
x = 0
s = 0
while x < 20:
    x = x + 2
    s = s + x
print("[Det som printes er...]", s)
```

Kom også med et forslag til tekst som kan erstatte `[Det som printes er...]`.


## Fasit

**a)**
Løkken kjører så lenge $n < 11$. Den skriver ut $n$ og øker deretter $n$ med $1$. Første verdi er $1$, siste gang $n$ skrives ut er når $n = 10$.

**Svar:** Programmet skriver ut tallene $1, 2, 3, \ldots, 10$ (hvert tall på egen linje).

[STEG]

**b)**
Start: $x = 0$, $s = 0$.

Hver runde: $x$ øker med $2$, deretter $s \leftarrow s + x$.
Verdiene som legges til $s$ er $2, 4, 6, \ldots, 20$.

Når $x = 20$ er $x < 20$ usann, og løkken stopper.
Summen av de ti første positive partallene:
$2 + 4 + \cdots + 20 = 10 \cdot 11 = 110$.

Forslag til utskriftstekst: `"Summen av partallene fra 2 til 20 er"`.

**Svar:** Programmet summerer partallene fra $2$ til $20$ og skriver ut $110$. Forslag: `Summen av partallene fra 2 til 20 er`.

## Starter

```python
x = 0
s = 0
while x < 20:
    x = x + 2
    s = s + x
print("Summen av partallene fra 2 til 20 er", s)
```
