Faktoriser ved å løfte ut felles binomial:

**a)** $x(x + 5) + 2(x + 5)$

**b)** $3(y - 1) - x(y - 1)$

**c)** $a(a - 4) - 3(a - 4)$

## Hint

Parentesen som står i begge ledd, kan løftes ut som felles faktor.

## Fasit

**a)**
$x(x + 5) + 2(x + 5) = (x + 5)(x + 2)$

**Svar:** $(x + 5)(x + 2)$

[STEG]

**b)**
$3(y - 1) - x(y - 1) = (y - 1)(3 - x)$

**Svar:** $(y - 1)(3 - x)$

[STEG]

**c)**
$a(a - 4) - 3(a - 4) = (a - 4)(a - 3)$

**Svar:** $(a - 4)(a - 3)$
