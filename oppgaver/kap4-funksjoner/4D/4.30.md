Gitt polynomet $P(x) = \frac{x^4 - x^3 + 2x^2 - x + 3}{x^2 + 1}$.

**a)** Utfør polynomdivisjon.

**b)** Skriv funksjonen på rest-form og forklar grafens oppførsel for store verdier av $x$.

## Hint

Pass på at du gjør nøyaktige mellomregninger i divisjonen av $x^4$.

## Fasit

**a)**
Vi utfører polynomdivisjonen $(x^4 - x^3 + 2x^2 - x + 3) : (x^2 + 1)$:

$(x^4 - x^3 + 2x^2 - x + 3) : (x^2 + 1) = x^2 - x + 1$
$-(x^4 + x^2)$
$\rightarrow -x^3 + x^2 - x + 3$
$-(-x^3 - x)$
$\rightarrow x^2 + 3$
$-(x^2 + 1)$
$\rightarrow 2$ (dette er resten)
[STEG]

**Svar:** Resultatet av polynomdivisjonen er $x^2 - x + 1$ med rest $2$.
[STEG]

**b)**
Vi kan nå skrive funksjonen på rest-form (svar fra divisjon + brøk med rest og nevner):
$P(x) = (x^2 - x + 1) + \frac{2}{x^2 + 1}$

For svært store (eller svært små negative) verdier av $x$ vil verdien av nevneren i restbrøken ($x^2 + 1$) bli enormt stor.
Dermed vil verdien av brøken nærme seg $0$:
$\frac{2}{\text{stort tall}} \rightarrow 0$

Når brøken forsvinner mot $0$, vil grafen til $P(x)$ legge seg nærmere og nærmere grafen til andregradspolynomet.
[STEG]

**Svar:** På rest-form kan funksjonen skrives som $P(x) = x^2 - x + 1 + \frac{2}{x^2 + 1}$. For store verdier av $x$ vil brøken gå mot $0$, og funksjonen vil oppføre seg som parabelen $y = x^2 - x + 1$.
