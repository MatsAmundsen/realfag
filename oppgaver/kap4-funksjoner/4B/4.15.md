Funksjonen $f$ går gjennom punktene $(0, 2)$ og $(4, 6)$. Funksjonen $g$ går gjennom $(0, 5)$ og $(5, 0)$.

**a)** Bestem uttrykkene til $f$ og $g$.

**b)** Løs $f(x) = g(x)$ eksakt.

## Hint

Bruk punktene til å finne stigningstall og konstantledd for hver funksjon. Sjekk spesielt punktene der $x = 0$.

## Fasit

**a)**
Vi starter med å finne uttrykket for $f(x) = a_f x + b_f$:
Linjen går gjennom $(0, 2)$, noe som betyr at konstantleddet $b_f$ er $2$.
Vi finner stigningstallet $a_f$ ved å bruke topunktsformelen med de to oppgitte punktene:
$a_f = rac{6 - 2}{4 - 0} = rac{4}{4} = 1$
Dette gir oss funksjonen $f(x) = 1x + 2$, altså $f(x) = x + 2$.

Så finner vi uttrykket for $g(x) = a_g x + b_g$:
Linjen går gjennom $(0, 5)$, noe som betyr at konstantleddet $b_g$ er $5$.
Vi regner ut stigningstallet $a_g$ med de to oppgitte punktene:
$a_g = rac{0 - 5}{5 - 0} = rac{-5}{5} = -1$
Dette gir oss funksjonen $g(x) = -1x + 5$, altså $g(x) = -x + 5$.

**Svar:** $f(x) = x + 2$ og $g(x) = -x + 5$

**b)**
Vi setter funksjonsuttrykkene lik hverandre for å løse likningen $f(x) = g(x)$.

$x + 2 = -x + 5$

Vi samler $x$-ene på venstre side og tallene på høyre side:
$x + x = 5 - 2$

Vi slår sammen:
$2x = 3$

Vi deler på $2$ for å få $x$ alene:
$x = rac{3}{2} = 1.5$

**Svar:** $x = 1.5$
