Utfør polynomdivisjonen $(x^2 + 3x + 1) : (x + 1)$.

**a)** Finn kvotient og rest.

**b)** Skriv $x^2 + 3x + 1$ på formen $(\text{divisor}) \cdot (\text{kvotient}) + \text{rest}$.

**c)** Kontroller ved å gange ut.

## Hint

$x + 1$ går ikke opp. Del første ledd $x^2 : x = x$, trekk fra, og fortsett. Resten blir et tall.

## Fasit

**a)**
$x^2 : x = x$. Trekk fra $x(x + 1) = x^2 + x$:

$(x^2 + 3x + 1) - (x^2 + x) = 2x + 1$.

$2x : x = 2$. Trekk fra $2(x + 1) = 2x + 2$:

$(2x + 1) - (2x + 2) = -1$.

Kvotient $x + 2$, rest $-1$.

**Svar:** kvotient $x + 2$, rest $-1$

[STEG]

**b)**
$x^2 + 3x + 1 = (x + 1)(x + 2) - 1$

**Svar:** $(x + 1)(x + 2) - 1$

[STEG]

**c)**
$(x + 1)(x + 2) = x^2 + 3x + 2$, deretter $x^2 + 3x + 2 - 1 = x^2 + 3x + 1$. Stemmer.

**Svar:** Kontroll OK
