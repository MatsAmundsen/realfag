Divisjonen (x³ - 4x² + cx - 12) : (x - 3) går opp uten rest. Bestem c.

## Hint

Bruk restteoremet: Siden det ikke blir noen rest, må uttrykket bli lik null når du setter inn x = 3.

## Fasit

P(3) = 0 ⇒ 3³ - 4(3)² + c(3) - 12 = 0 ⇒ 27 - 36 + 3c - 12 = 0 ⇒ -21 + 3c = 0 ⇒ 3c = 21 ⇒ c = 7.
