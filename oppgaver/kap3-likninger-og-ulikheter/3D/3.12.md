Bruk abc-formelen til å løse likningen:
a) 2x² - 8x + 6 = 0
b) a² - 3a = 4
c) c² - 10c + 25 = 0
d) 2x² + 5x - 3 = 0
e) Forenkle brøken: (2y² + 5y - 3) / (y² + 5y + 6)

## Hint

For å forenkle brøken i e), må du faktorisere både teller og nevner ved å finne nullpunktene først.

## Fasit

**a)** x = 1 eller x = 3.
**b)** a² - 3a - 4 = 0 ⇒ a = 4 eller a = -1.
**c)** (c - 5)² = 0 ⇒ c = 5.
**d)** x = 1/2 eller x = -3.
**e)** Teller faktoriseres til 2(y - 1/2)(y + 3) = (2y - 1)(y + 3). Nevner faktoriseres til (y + 2)(y + 3). Brøken forkortes til (2y - 1) / (y + 2).
