Løs likningene:

**a)** $(x + 3)(4 - x) = 0$

**b)** $x^2 + 5x = 0$

**c)** $2x^2 - 50 = 0$

## Hint

Et produkt er null når minst én av faktorene er null. I **c)** kan du først dele på $2$, og deretter bruke differanse av to kvadrat.

## Fasit

**a)**
$x + 3 = 0$ eller $4 - x = 0$
$x = -3$ eller $x = 4$

**Svar:** $x = -3 \vee x = 4$

[STEG]

**b)**
$x(x + 5) = 0 \Rightarrow x = 0$ eller $x = -5$

**Svar:** $x = 0 \vee x = -5$

[STEG]

**c)**
$2x^2 = 50 \Rightarrow x^2 = 25 \Rightarrow x = \pm 5$

(eller: $2(x^2 - 25) = 0 \Rightarrow (x-5)(x+5) = 0$)

**Svar:** $x = 5 \vee x = -5$
