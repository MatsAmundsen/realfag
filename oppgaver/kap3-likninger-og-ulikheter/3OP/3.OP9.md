Polynomet $P$ er gitt ved $P(x) = 2x^3 + 4x^2 - 10x - 12$.

**a)** Forklar at divisjonen $P(x) : (x + 1)$ går opp.

**b)** Gjennomfør divisjonen.

**c)** Skriv $P(x)$ som et produkt av lineære faktorer.

**d)** Løs likningen $P(x) = 0$.


## Fasit

**a)**
$P(-1) = 2(-1)^3 + 4(-1)^2 - 10(-1) - 12 = -2 + 4 + 10 - 12 = 0$.
Siden $P(-1) = 0$, går $x + 1$ opp i $P(x)$.

**Svar:** $P(-1) = 0$, derfor går det opp.

[STEG]

**b)**
$(2x^3 + 4x^2 - 10x - 12) : (x + 1) = 2x^2 + 2x - 12$

Kontroll: $(x+1)(2x^2 + 2x - 12) = 2x^3 + 2x^2 - 12x + 2x^2 + 2x - 12 = 2x^3 + 4x^2 - 10x - 12$.

**Svar:** $2x^2 + 2x - 12$

[STEG]

**c)**
$2x^2 + 2x - 12 = 2(x^2 + x - 6) = 2(x + 3)(x - 2)$

Dermed $P(x) = 2(x + 1)(x + 3)(x - 2)$

**Svar:** $P(x) = 2(x + 1)(x + 3)(x - 2)$

[STEG]

**d)**
$2(x+1)(x+3)(x-2) = 0 \Rightarrow x = -1 \vee x = -3 \vee x = 2$

**Svar:** $x = -3 \vee x = -1 \vee x = 2$
