Løs $\dfrac{3}{x + 1} = \dfrac{2}{x - 1}$.

Oppgi først hvilke $x$ som *ikke* er tillatt, og sett prøve i svaret.

## Hint

Nevnerne kan ikke være $0$. Kryssmultiplikasjon gir $3(x - 1) = 2(x + 1)$.

## Fasit

Ikke tillatt: $x = -1$ og $x = 1$.

$3(x - 1) = 2(x + 1)$

$3x - 3 = 2x + 2$

$3x - 2x = 2 + 3$

$x = 5$

[STEG]

$x = 5$ er ulik $\pm 1$, så den er tillatt.

Prøve: $\dfrac{3}{6} = \dfrac{1}{2}$ og $\dfrac{2}{4} = \dfrac{1}{2}$. Stemmer.

**Svar:** $x = 5$
