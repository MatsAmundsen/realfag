Løs og sett prøve: $3(2x - 1) - x = 4(x + 2)$

## Hint

Løs opp parentesene først, samle $x$-ledd, så tall.

## Fasit

$6x - 3 - x = 4x + 8$

$5x - 3 = 4x + 8$

$5x - 4x = 8 + 3$

$x = 11$

[STEG]

**Prøve:** VS $3(22 - 1) - 11 = 63 - 11 = 52$. HS $4(11 + 2) = 52$.

**Svar:** $x = 11$
