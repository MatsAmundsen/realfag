Løs ved produktregelen:

**a)** $x^2 + 5x = 0$

**b)** $2x(x - 3) = 0$

**c)** $x^2 = 7$ (eksakt svar)

## Hint

Løft $x$ utenfor parentes i **a)**. I **c)** lar du kvadratroten stå.

## Fasit

**a)**
$x(x + 5) = 0 \Rightarrow x = 0$ eller $x = -5$.

**Svar:** $x = 0 \vee x = -5$

[STEG]

**b)**
$2x = 0$ eller $x - 3 = 0 \Rightarrow x = 0$ eller $x = 3$.

**Svar:** $x = 0 \vee x = 3$

[STEG]

**c)**
$x = \pm \sqrt{7}$

**Svar:** $x = \pm \sqrt{7}$
