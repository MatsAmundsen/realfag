Løs andregradslikningene. Bruk produktregelen der det er mulig:
a) x(x - 4) = 0
b) 0 = -25 + k²
c) x² + 6x = 0
d) 16b + b² = 0
e) (k - 3)(k + 8) = 0

## Hint

For å bruke produktregelen må du faktorisere uttrykket først, f.eks. trekke ut en felles x.

## Fasit

**a)** x = 0 eller x = 4.
**b)** k² = 25 ⇒ k = ±5.
**c)** x(x + 6) = 0 ⇒ x = 0 eller x = -6.
**d)** b(16 + b) = 0 ⇒ b = 0 eller b = -16.
**e)** k = 3 eller k = -8.
