Hva er programmering?

Et program er en oppskrift. Du skriver instruksjoner, og datamaskinen utfører dem nøyaktig i den rekkefølgen du har skrevet — linje for linje, ovenfra og ned.

Forskjellen fra en matoppskrift: datamaskinen gjetter aldri. Glemmer du et komma, eller skriver Print i stedet for print, stopper den og sier ifra. Det er ikke «dumt» — det betyr at språket er strengt, så vi kan stole på det.

Hvorfor Python?

I 1T bruker vi språket Python. Det er laget for å være lesbart: print("Hei") betyr akkurat «skriv ut Hei». Samme ideer (variabler, if, løkker) finnes i andre språk, så det du lærer her, tar du med deg videre.

Tre regler å ha i bakhodet:
  1. Koden kjører ovenfra og ned, én linje om gangen.
  2. Python skiller på store og små bokstaver. Print er ikke det samme som print.
  3. Innrykk (mellomrom foran linjen) viser hva som hører sammen. Vanligvis 4 mellomrom.
2

print — vis noe på skjermen

print er den første kommandoen du trenger. Den tar det som står i parentesen og viser det som utskrift.

print("Hei, 1T!")
print(2 + 5)

Hermetegn " " (eller ' ') betyr tekst. Python skal ikke regne på teksten, bare vise den. Uten hermetegn betyr det et regnestykke eller et navn (en variabel).

print("2+5") skriver bokstavelig 2+5.
print(2+5) regner først, og skriver 7.
Vanlig nybegynnerfeil: print(Hei) uten hermetegn. Da leter Python etter en variabel som heter Hei. Finnes den ikke, får du NameError.
3

Variabler, typer og input

En variabel er en merkelapp på en verdi. Tenk en eske med navn på. Du putter noe i esken med =, og henter det frem ved å bruke navnet.

navn = "Nora"
alder = 16
print(navn)
print(alder + 1)

Etter første linje inneholder esken navn teksten Nora. Etter andre linje inneholder alder tallet 16. Siste linje skriver 17 — vi endrer ikke esken, vi bare bruker verdien i et regnestykke.

% er viktig: n % 2 == 0 betyr «n er partall» (ingen rest når du deler på 2).

input — spør brukeren

input() leser det noen skriver, men svaret er alltid tekst. Skal du regne med tallet, pakk det inn i int() eller float().

n = int(input("Skriv et tall: "))
print(n * 2)
Uten int: "4" * 2 blir "44" (tekst gjentas), ikke 8. Det er derfor P.04 i oppgavene er en klassisk felle.
f-streng — sette verdier inn i tekst
navn = "Mats"
print(f"Jeg heter {navn}.")

Bokstaven f foran hermetegnene betyr at {navn} byttes ut med innholdet i variabelen.

Vilkår: if, elif og else

Et vilkår er et spørsmål med ja/nei-svar: «Er alderen minst 18?» I koden skriver vi det med sammenligninger. Svaret er True (sant) eller False (usant).

SkrivBetyr
==er lik (to likhetstegn! Ett = betyr «lagre i variabel»)
!=er ikke lik
< <= > >=mindre / minst / større / høyst

if kjører koden under bare hvis vilkåret er sant. else er «ellers». elif («else if») er neste spørsmål, hvis det første var usant.

poeng = 85
if poeng >= 90:
    print("A")
elif poeng >= 80:
    print("B")
else:
    print("C eller lavere")

Her er 85 ikke ≥ 90, men ≥ 80, så utskriften blir B. Rekkefølgen er viktig: sjekk den strengeste grensen først (90 før 80). Ellers ville 95 også truffet «minst 80».

Innrykk er selve blokken. Alt som er rykket inn under if, hører til den. Linjer uten innrykk kjører alltid, etterpå.

Løkker: for og while

En løkke gjentar de samme linjene flere ganger, så du slipper å kopiere kode.

for — kjent antall ganger

range(5) gir tallene 0, 1, 2, 3, 4 (fem tall, starter på 0). range(1, 6) gir 1 til 5 — stopptallet er ikke med.

for i in range(1, 6):
    print(i * i)

Dette skriver kvadrattallene 1, 4, 9, 16, 25. Variabelen i får en ny verdi hver runde.

while — så lenge noe er sant

Bruk while når du ikke vet på forhånd hvor mange runder det blir: «fortsett til saldoen er minst 500».

n = 3
while n > 0:
    print(n)
    n = n - 1

Første runde: n er 3 (sant, skriv 3, trekk fra 1). Så 2, så 1. Når n blir 0, er vilkåret usant, og løkken stopper.

Evig løkke: Glemmer du å endre n inni løkken, blir vilkåret alltid sant. Programmet henger. Stopp og rett koden. I kodeskriveren her stoppes lange kjøringer automatisk.
Løkke + if

Inne i en løkke kan du stille spørsmål til hvert tall:

for n in range(1, 8):
    if n % 2 == 0:
        print(n)

Skriver partallene 2, 4, 6.
